# 🚀 About TITUS-BOT QUANTUM 

TITUS-BOT-X is a modern WhatsApp automation and AI assistant bot designed for performance, intelligent interactions, and stable deployment.

Designed using:
- Node.js
- Baileys
- Firebase
- Google AI
- Render Cloud

---

# ✨ Main Features

## 🤖 AI Assistant
- Smart conversations powered by Google Gemini
- Commands:
  - `.ai`
  - `.gpt`

## 👀 Auto Status System
- Automatic status viewing
- Automatic reactions
- Human-like interaction delays

## 🔐 Secure Session Storage
- Firebase Firestore authentication
- Persistent login sessions
- Restart-safe deployments

## ⚙ Admin Controls
- Enable or disable features
- Owner-only controls

Example:
```bash
.enable ai
.enable autostatus
.disable premium
```

# 🛠 Installation

## Clone Repository

```bash
git clone https://github.com/Titus-bot-hue/TITUS-BOT-X.git
cd TITUS-BOT-X
```

Install packages:

```bash
npm install
```

Start:

```bash
npm start
```

---

# 🔥 Firebase Setup

Create Firebase Project

Add:

```env
FIREBASE_PROJECT_ID=
FIREBASE_PRIVATE_KEY=
FIREBASE_CLIENT_EMAIL=
```

---

# 🔑 Environment Variables
